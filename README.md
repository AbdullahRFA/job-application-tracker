# Job Application Tracker Web Platform

A scalable, role-based web platform for tracking job applications, deadlines, interview stages, and administrative audit logs.

## Architecture (NFR-10 & NFR-15)
- **/backend**: RESTful JSON API (`/api/v1/`) with TypeScript, Prisma ORM, and Supabase PostgreSQL.
- **/frontend**: Responsive client application with TypeScript and Tailwind CSS.
